# AGY Customizations & Tools

A collection of customizations, extensions, and developer tooling for Google Antigravity (AGY).

---

## Directory

### CLI
- **[Status Bar Suite](CLI/customization/README.md)**:
  - **Interactive Installer (`CLI/customization/install.sh`)**: Terminal UI to preview and configure status bar parts.
  - **Unified Line (`status_bar.sh`)**: Combines all parts of the status bar onto a single line.
  - **Git Status (`git_status_bar.sh`)**: Git tracking part of the status bar.
  - **Timer (`timer_status_bar.sh`)**: Session uptime and round timer part of the status bar.
  - **Quota (`quota_status_bar.sh`)**: Consumer account dual-window request quota part of the status bar.
  - **Context Window (`context_status_bar.sh`)**: Token consumption and context window part of the status bar.
- **[MCP Server Manager](CLI/mcp/README.md)**:
  - **Interactive TUI (`CLI/mcp/manage.sh`)**: Terminal UI to configure, inspect, and manage MCP servers.
